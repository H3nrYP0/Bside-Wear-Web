# Bside Wear Web

Aplicación web para **B-Side Wear**, marca de moda urbana independiente ubicada en Belén Rincón, Medellín.

## Stack

- Frontend: React
- Backend: Flask + Python
- Base de datos: PostgreSQL (Neon)
- Imágenes: Cloudinary
- Hosting: Render
